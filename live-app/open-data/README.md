# 三位一体辅助系统 · 开放数据包

> 版本：v2.0.0 ｜ 更新时间：2026年9月 ｜ 院校数：45 所（其中 2026 年招生 38 所）

本目录为浙江省三位一体院校数据的开放数据包，随应用版本同步更新。

## 范围说明

本包收录 **浙江省「三位一体」招生院校**（不含综合评价招生）。

- 「类别」列出省内地方属三位一体 / 高水平三位一体（2026 年官方口径分别为 32 所 / 6 所）；
- 「2026是否招生」为「否」的院校，是 2026 年未参与三位一体招生、仅保留历史年份数据的院校（共 7 所），它们只在 2025 及更早年份的统计中有意义；
- 各校缺失的满意度、住宿留证与来源信息一律留空，**未做任何推算或填充**。

## 编码说明

所有 CSV 与 Markdown 文件均为 UTF-8（含 BOM），可直接用 Excel / WPS 打开，不会乱码；JSON 为纯 UTF-8（无 BOM）以便程序解析。

> 说明：本目录（仓库）内的文件名保持英文，便于版本管理与程序引用；在应用内下载时，文件名会以中文呈现（如「院校总览.csv」对应 `schools.csv`、本文件对应「数据说明.md」），两者内容完全一致。

## 文件说明

| 文件 | 说明 |
|---|---|
| schools.json | 完整结构化数据（45 所院校全字段），适合程序化使用 |
| schools.csv | 院校总览：类别、2026是否招生、基础信息、学费、联系方式、满意度、住宿、最低综合分（原始分｜百分制）与数据年份 |
| formulas.csv | 折算规则：学考 A/B/C/D 分值、学考/校测/高考满分与三项权重、口径与来源 |
| majors.csv | 专业明细：招生专业、类别、选科要求与计划数 |
| admission.csv | 历年录取竞争比：报名/入围/录取人数与最低综合分 |
| exam-formats.csv | 校测形式：笔试科目、面试形式、体测与内容摘要 |
| application-steps.csv | 报名流程：各阶段名称、说明、截止时间与所需材料 |
| schools.md | 人类可读数据文档（含以上全部表格） |

## 数据维度

院校名称、校区地址、学费区间、学考折算规则、校测形式、招生专业与选科要求、历年报名/入围/录取数据、综合满意度（综合/环境/生活）、转专业限制、报名流程与材料、招生简章链接。

## 数据来源

浙江省教育考试院、各高校招生网、阳光高考网。
