# 三位一体辅助系统 · 开放数据包

本目录为浙江省三位一体院校数据的开放数据包，随应用版本同步更新。

## 文件说明

| 文件 | 说明 |
|---|---|
| schools.json | 完整结构化数据（15 所院校全字段），适合程序化使用 |
| schools.csv | 核心字段表格，Excel / WPS 可直接打开 |
| schools.md | 人类可读数据文档 |

## 数据维度

院校名称、校区地址、学费区间、学考折算规则、校测形式、招生专业与选科要求、历年报名/入围/录取数据、综合满意度（综合/环境/生活）、转专业限制、报名流程与材料、招生简章链接。

## 数据来源

浙江省教育考试院、各高校招生网、阳光高考网。

## GitHub 上传指引

将本数据包推送至你的 GitHub 仓库，步骤如下：

```bash
# 1. 进入项目目录
cd 你的项目目录

# 2. 初始化仓库（若尚未初始化）
git init

# 3. 添加数据包文件
git add open-data/

# 4. 提交
git commit -m "feat: 更新开放数据包 v1.0.0"

# 5. 关联远程仓库（替换为你的仓库地址）
git remote add origin https://github.com/你的用户名/你的仓库.git

# 6. 推送
git push -u origin main
```

> 提示：推送到 GitHub 后，可在应用内"开放数据"页填入仓库地址，方便用户直接访问。
