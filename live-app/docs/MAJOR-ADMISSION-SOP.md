# 分专业录取综合分 · 数据维护 SOP

> 目的：三位一体录取按"专业内综合分"排序，工具需为每个招生专业提供「历史录取综合分参考线」。
> 本文档沉淀"官方公示 → 整理映射 → 数据回写 → 前端消费 → 校验发版"的完整流程，供在其它院校复用。
> 维护时间：2026-09-08 ｜ 适用范围：live-app（唯一维护版）

---

## 1. 目的与适用范围

- 校级 `school.admission[].minScore` 只是全校参考线；填报时考生应按**目标专业**的录取综合分判断冲稳保。
- 本机制为每个 `school.majors[]` 专业附加 `admissionStats`（该专业某一年份的录取最低综合分 + 来源）。
- 当前进度：**浙江大学 3 个示例专业**（计算机科学与技术 / 临床医学 / 法学）为试点；本版因无可靠数据**未写入 admissionStats**（详见附录 B），前端两态逻辑已就绪。

## 2. 官方公示入口定位方法（以浙大为例）

| 环节 | 位置 | 时间 |
|---|---|---|
| 招生简章（口径依据） | zdzsc.zju.edu.cn → 三位一体栏目，如 2026 简章 `.../0511/c87247a3161363/page.htm` | 5 月 |
| 校测入围名单 | 招生网公告（按专业公布入围名单，含面试成绩） | 6 月 |
| **录取结果** | 招生网公告，**但仅指引登录报名系统查询**，无公开附件 | 7 月上旬 |

定位做法：

1. 站内/搜索引擎查 `浙江大学 20xx年 三位一体 录取结果 公布`，域名限 `zdzsc.zju.edu.cn`；
2. 点开通知页确认：**若正文只是"请登录 bm.chsi.com.cn 查询"且无附件/列表 → 该届无公开名单**；
3. 年份降级策略：2026 不可得则找 2025（网址形如 `.../0709/c87242a3068732/page.htm`），同样多为登录查询；
4. 需要确认"分专业录取最低综合分"且能落到官方文本时，才可作为 `sourceUrl`。

## 3. 名单解析规则

- 综合分量纲：本应用统一为**百分制**（浙大综合 = 高考折算×85% + 面试×10% + 学考×5%）。若公示给出 750 制或其它口径，需先换算到百分制并在 `note` 注明。
- 字段关注：专业名称、录取最低综合分；有名册时取 min/avg/count。
- 专业名映射约定：公示专业名 ≠ 站内专业名时（如 公示"临床医学(5+3一体化)" → 站内"临床医学"），在 `note` 写明映射关系；无法可靠对应的**不写**。
- 招生专业以官方最新简章为准，站内 majors 若与简章不符应先修 majors。

## 4. 数据 Schema（向前兼容、可缺省）

在 `SCHOOLS[i].majors[j]` 上追加：

```js
admissionStats:{
  year: 2026,             // 数据对应届，必填
  minScore: 90.05,        // 该专业录取最低综合分（百分制）必填
  avgScore: 91.2,         // 可选
  count: 32,              // 可选：该专业录取人数
  sourceUrl: 'https://...',// 必填：官方公示页（第三方转载须注明并谨慎）
  note: '公示名映射/口径说明；或"第三方转载，非官方待核实"'
}
```

**约定：`admissionStats` 缺失 = 暂无专业录取线；UI 显示"暂无/按校级线"，绝不显示编造数值。**

## 5. 数据回写步骤

1. 编辑 `live-app/index.html`，定位到对应 school 记录（每校一行）与其 `majors:[...]`；
2. 在对应专业对象尾追加 `admissionStats`（对象字段间用逗号，保持单行可读）；
3. 语法自检：临时脚本 `new Function(整段<script>)`（参考附录 C）或本地浏览器打开计算器验证；脚本用完删除。

## 6. 前端消费点（改动均已在 live-app/index.html）

| 位置 | 组件 | 行为 |
|---|---|---|
| 综合分计算器 | `CalculatorPage`（约行 340-380） | 新增"选择专业"下拉（school.majors），`admissionStats` 存在时其下方显示"该专业 xx 年最低 xx 分 + 来源↗"；正算判定线 `专业线 ?? 校级线`，有专业线按专业线算冲稳保 |
| 院校详情页 | `SchoolDetailPage` 招生专业卡（约行 326） | 每个专业右区在"招N人"后追加绿色 badge：`{year}年最低 {score} 分 ↗`（有 sourceUrl 时整 badge 可点击） |
| 逻辑 | `line`/`tierLabel`（组件内局部计算） | 判定口径 diff>5 保底 / <-5 冲刺 / 其余稳妥（与 calcResult 一致） |

## 7. 降级与防伪策略（重要）

- 官网无公开名单（登录限定）时，**默认不写** admissionStats，UI 回落校级线；
- 只有用户确认可用第三方整理值时，才可写入并满足：`sourceUrl` 指向可访问来源 + `note` 明确"非官方、待核实"；
- 两届都拿不到的专业一律留空，绝不用旧数据硬凑、绝不自造数值；
- 回填来源必须是当时可见页面；页面下线后仍保留 URL 并补 note。

### B. 本次调研结论（2026-09-08）

- 浙大 2026 与 2025 的"三位一体录取结果公布"均**仅指引考生登录 bm.chsi.com.cn 查询**，无公开的"专业+综合分"名单/附件；
- 第三方资料以**首考入围线、高考投档线**为主，口径与"录取最低综合分（百分制）"不一致；零星报道（如某专业最低 90.05）不构成覆盖 3 个示例专业的可靠数据；
- 因此本版 `zju` 的 3 个 majors **不写 admissionStats**（计算机科学与技术 / 临床医学 / 法学均显示"暂无该专业录取线"）；等用户从报名系统导出名单、或官方/可靠资料出现后，按第 4-5 节回填即可，前端无需再改。
