# 三位一体辅助系统

浙江三位一体（学考 + 校测 + 高考）报考辅助系统，提供院校数据、综合分计算与报考决策工具，支持 PWA 离线使用。

## ✨ 功能

- 🔍 **院校筛选**：15 所省属/部属院校，支持选科筛选与冲稳保分层
- 🧮 **综合分计算器**：正算 / 反向推算，直观换算三一综合分
- ⚖️ **三一 vs 普通高考**：两条升学路径多维度对比
- 🏫 **院校详情**：校测内容、满意度、住宿条件、转专业限制、招生简章
- 💬 **树洞社区**：匿名分享，分类 / 点赞 / 回复 / 置顶 / 举报
- 📝 **数据纠错**：发现数据问题一键反馈
- 📦 **开放数据下载**：院校数据包（JSON / CSV / Markdown）
- 📱 **PWA**：可添加到主屏幕，核心功能离线可用

## 🚀 本地运行

```bash
node server.cjs
# 访问 http://localhost:8080
```

> 无需 `npm install`。前端为单文件 `index.html`（React 18 UMD 无构建），后端为 Node 原生 http。

## 📦 开放数据

`open-data/` 目录提供整理好的院校数据：

| 文件 | 说明 |
|------|------|
| `schools.json` | 完整结构化数据（15 所院校全字段） |
| `schools.csv` | Excel / WPS 可直接打开 |
| `schools.md` | 人类可读数据文档 |

数据来源：浙江省教育考试院、各高校招生网、阳光高考网。

## 🗂 目录结构

```
├── index.html        # 前端（React 单文件，含全部数据与页面）
├── server.cjs        # 后端（静态服务 + 树洞/计数/纠错 API）
├── manifest.json     # PWA 清单
├── sw.js             # Service Worker（离线缓存）
├── icon.svg / png    # 应用图标
├── open-data/        # 开放数据包（可推送 GitHub）
├── tools/            # 数据导出工具
└── data/             # 运行时数据（不入库）
```
